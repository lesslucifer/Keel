E-SEED.W8 — Doc tiers and distillation

A config-driven T0–T3 classifier, tiers recorded in doc/v1, and the two halves of UC-DOC-3 enforced by the merge gate: no T3 doc tracked at an epic tip, and no T3 doc archived without saying where its content went.

v1 · 2026-11-07 · Keel · T3 WU plan · epic: E-SEED · status: ready (dispatch does not wait on sign-off; the owner reviews asynchronously)

Requirement

W3's check 6 confirms that doc/v1 lists exactly the docs the range changed, but nothing knows what tier a doc is. As a result, a working doc (T3) can stay in git forever, and a working doc can be deleted without its durable content ever reaching a lasting doc. The W8 card on the epic plan says W8 "classifies each governed doc into its T0–T3 tier and enforces the distillation checklist (what a tracked doc must be absorbed into before archive)". Its expected fixture is: "a T3 doc wrongly left tracked is flagged, and an untracked, unabsorbed doc trips the same check." This WU closes UC-DOC-3: at an epic tip, no T3 doc is tracked and every changed doc is accounted for in doc/v1.

Source. This is a port of Trawler's docs/documentation-system.html together with xtask/src/notes.rs · tier_of / is_expected_tracked_doc / DistilledTo and gate.rs · check_docs / check_tracked_docs. The table below separates what carries over generically from what is specific to Trawler.

One classifier and one doc-set function, shared by the note writer and the gate, so the two can never disagree. This follows the same pattern as code_diff_hash.

Config shape

[docs]
root = "docs/"

# Optional. Omitted = this default (with docs.root substituted for "docs/").
# Globs: * = within one path segment, ** = any depth, ? = one char.
# Checked T3, T2, T1, T0 - first tier that matches wins, so a broad T1 glob can never hide a T3 doc.
[docs.tiers]
T0 = ["AGENTS.md", "CLAUDE.md"]
T1 = ["docs/*"]
T2 = ["docs/use-cases/**", "docs/decisions/**", "docs/backlog/**"]
T3 = ["docs/work/**", "docs/.archive/**"]
  • Classifier notes::tier_of(cfg, path) -> Option<&str>. Globs are translated to the already-installed regex crate, so there is no new dependency. When [docs.tiers] is given, each tier's list is exactly what is written there. A tier left out is empty and does not fall back to the default.
  • Doc set notes::doc_paths(repo, cfg, base, tip) = every changed path that is under docs.root or classifies as T0, plus every T3 doc deleted by any commit in base..tip that is absent at the tip. W3's two starts_with(docs.root) filters in the writer and in check 6 are replaced by it.
  • doc/v1: paths: [..] becomes changes: [{path, tier, distilled_to?}]. distilled_to is either a list of paths or the string "none: <why>", untagged as in Trawler. The schema stays /v1 because no note has been released yet.
  • Writer: keel notes write doc [--target R] [--distill <t3-path>=<doc>[,<doc>…]]…, where =none: <why> records a dead end. It refuses in four cases, per UC-NOTE-1 ("refuses a judgment the diff contradicts"): a doc that matches no tier, an archived T3 doc with no --distill, a --distill that names something other than a T3 doc archived in the range, and a target that is not a T1/T2 doc tracked at the tip.
  • Check 6 (6·doc-note) uses one shared notes::doc_problems for the writer's refusals and the gate's failures. A failure is any of: a doc in the set but not in the note, a note entry not in the set, a recorded tier that differs from the config-derived tier, an unclassified doc, or an archived T3 entry without valid distilled_to (empty, a "none:" with no reason, or a target that is not a T1/T2 doc tracked at the tip).
  • Exempt ranges still owe lineage. A docs-only range is exempt from doc evidence (UC-GATE-5), but an archive commit is always docs-only. If exemption applied there, nothing would ever check distillation. The rule here: a range whose doc set holds an archived T3 doc needs doc/v1 and check 6 even when exempt. This reads lineage as part of the "tracked-doc layout" that UC-GATE-5 never exempts. The receipt is still not written for an exempt range.
  • Epic layout: at an epic tip, whether exempt or not, every path from git ls-tree -r --name-only tip -- docs.root must classify as T0, T1 or T2. Anything else is red under 6·doc-note. The fix line for a T3 path is the archive step. The check sits in W3's marked slot in verify(), ahead of the exemption.

Explicitly not this WU

  • The distill skill: the six checklist questions, guidance on writing a T2 entry, and the KB index rule. These belong to W6, because they are judgment and the CLI cannot check them.
  • Checking that the archived file really sits in docs/.archive/. That directory is gitignored and local, so the gate on another machine cannot see it.
  • Trawler's T2 index rule (one *-index.html per KB), the T0 200-line cap, distills sentences, t2_waived, and the design-pack retirement order. See the open points.
  • Changes to keel verify-doc. It checks a single file at write time and has no range or tip, while UC-DOC-3 is a property of the range and the tip. See open point 4.
  • keel mr, check 8 (W4, which runs in parallel), the seed plan, the other WU-plan docs, and anything in Trawler.

Maps to

UC-DOC-3 (at an epic tip no T3 doc is tracked, and every changed doc is accounted for in doc/v1 with its tier) · UC-NOTE-1 (in part: notes write doc derives the doc tiers from the tree and refuses a distillation claim that the diff contradicts) · UC-GATE-5 (the epic tracked-doc layout is never exempt).

Expected result

Per the W8 card: in a fixture doc tree, a T3 doc wrongly left tracked at the epic tip is flagged by verify-dod epic. A T3 doc removed from git with no distilled_to trips the same check (6·doc-note). Once it is archived with lineage to a tracked T2 doc, the epic is green. doc/v1 records each doc's tier as the config classifies it, and a tier tampered in the note is red.

Test plan

The new cases go in tests/verify_dod.rs and reuse its fixture and helpers (a temp repo, the real binary, and notes edited in place). tests/cli.rs's doc-note assertion moves from paths to changes.

  • Config classifies: a custom [docs.tiers] in the fixture means notes write doc records T1/T2/T3 for docs in the matching directories. A doc that matches no glob is refused by name.
  • Misclassified tier is red: the WU's doc entry is tampered from T1 to T3, and verify-dod wu fails 6·doc-note. The existing "missing path" tamper still fails it.
  • Tracked T3 at epic tip is red: a WU adds docs/work/plan.html, merges --no-ff, and verify-dod epic fails 6·doc-note naming the tracked work doc.
  • Archive without lineage is red, with lineage is green: the epic tip git rms the plan and adds a T2 decision. notes write doc with no --distill is refused. With --distill docs/work/plan.html=docs/decisions/d.html the epic is green. The plan is created and archived inside the epic range, which exercises the netted-out doc set. If distilled_to is stripped from the note, the result is red.

Open points for the owner

#PointDecided here
1How tiers are assigned. The options were path convention (Trawler), a per-doc tag (for example data-tier), or config globs.Config globs, defaulting to Trawler's layout rooted at docs.root. A path rule needs no edit to each doc, works for non-HTML files under docs/, and a doc's tier changes only when it moves, which is how Trawler already thinks about tiers. A tag would let a T3 doc relabel itself to escape archiving.
2Glob overlap. T1 = ["docs/**"] would also match docs/work/.Tiers are checked T3 first and T0 last, and the first match wins. Misfiling a doc as more permanent is the failure that hides it from the archive check, so T3 has to win any overlap.
3What "archived" means to the gate. Trawler's rule is git rm plus a move to docs/.archive/.A T3 doc deleted in the range and absent at the tip. The move into the gitignored archive is a local convenience that git cannot see, so it is not checked. docs/.archive/** is in the default T3 list so that accidentally tracking it is red at the epic tip.
4verify-doc vs verify-dod. The task allowed extending either. The W8 card says W8 "adds the tier assignment and the archive/absorption check" next to W5's checklists.Only verify-dod (check 6) is extended. Both UC-DOC-3 halves need a tip and a range (what is tracked, what was deleted), and verify-doc runs on a single file at write time with neither. A tier that verify-doc could check per file would just repeat the gate.
5What the "distillation checklist" check actually checks. Trawler's checklist is six judgment questions, and its gate checks only that distilled_to is recorded.The check is stricter than Trawler's but still lean. An archived T3 doc needs distilled_to, and every target must be a T1 or T2 doc tracked at the tip, otherwise the entry must be an explicit "none: <reason>". It does not require the target to have changed in the same range, because distillation often lands in an earlier WU than the archive commit. The questions go to the distill skill (W6).
6Trawler's t2_waived (a WU or epic that changed code must update some T2 doc or give a reason) and the distills sentence on every entry.Not ported. Neither is in UC-DOC-3, and both are pure judgment text the gate can only check for being non-empty. Easy to add later as optional fields on doc/v1 if wanted.
7Exempt ranges and archive commits. UC-GATE-5 exempts docs-only diffs from doc evidence, yet every archive commit is docs-only.A range whose doc set contains an archived T3 doc needs doc/v1 and check 6 even when exempt. Read literally, the exemption would make the distillation check unreachable. This treats lineage as part of the epic tracked-doc layout, which UC-GATE-5 never exempts. Flag it if you read UC-GATE-5 more strictly.
8T0 docs in doc/v1. W3's doc set is "under docs.root". T0 (AGENTS.md) normally sits at the repo root.The doc set is under docs.root or classifies as T0, so an edit to the rules file is accounted for like any other doc ("every changed doc"). One side effect: a commit that touches AGENTS.md now needs a doc note at commit level, like any doc change.
9Unclassified docs. A path under docs.root that matches no tier glob (for example docs/img/x.png with the default).Red in check 6 and in the epic layout check, and refused by the writer. This matches Trawler's "tracked outside the expected doc locations". The fix is a glob in [docs.tiers].
10Schema change. doc/v1 paths becomes changes.Done in place at /v1, because no notes are in the wild yet (Keel gates itself only from W7). Any W4 code that reads DocNote.paths needs the one-word update. The router should check this at W4/W8 integration.
11Keel's own docs/work/ holds the E-SEED plan docs, all tracked.By design, these make an E-SEED epic gate red until they are distilled into docs/use-cases/ and docs/decisions/ per the epic's distillation plan, then archived. Nothing changes now, since E-SEED runs ungated (Q12).
