D1 · The DSH doc-gate plugin open

Build it in its own repo in the desktop-dsh project. DEC-54 records the contract and keel init prints the install line, but no such repo exists (checked 2026-11-14), so a DSH session has no doc check at all: a red doc's write comes back a success and the turn can close on it. The plugin runs keel verify-doc <path> in tools/post-execute after a first-party doc write or edit and returns {kind:'block', feedback} with the problem lines; it runs keel verify-doc over all docs in agent/turn-stopping and calls agent.steer() with the problems. Exit 0 is silent, and a draft is silent by construction. Its repo carries its own tests. The install line names the repo dsh-doc-gate, a placeholder until the repo is created. Source: E-DSH plan open point 3; E-DSH.W2 result.

D2 · The DSH router guard plugin open

A plugin that enforces the router's tool whitelist and Bash shapes on DSH. DSH has no shell-hook surface, so today the keel-router skill is the only guard on that host: nothing checks the whitelist, the brief path or the inline skills, and the skill tells the router to say that enforcement is missing (UC-ROUTE-6, DEC-55). Where a Claude Code project runs scripts/router-guard.jq as one fail-closed PreToolUse hook, the plugin would judge the same shapes at tools/pre-execute and deny every call the whitelist does not name, fail-closed. The plugin is a profile package; the whitelist itself stays the project's. Source: E-DSH plan open point 4; E-DSH.W3 result ("the honest gap").

D3 · The worker plugin's cold resume open

Wake a stopped worker's session instead of spawning a fresh one. dsh-worker-workspace (its own repo in the desktop-dsh project, HEAD a93dff2) starts a worker session in a worktree; there is no resume, so a worker that dies takes its context with it, and the router starts a fresh session with a new brief (DEC-55). A cold resume would wake that session with its workspace root, its transcript and its instructions intact, so a crashed worker's round does not start over. Deferred out of E-DSH as out of scope. Source: E-DSH plan non-goals; E-DSH.W3 result.
