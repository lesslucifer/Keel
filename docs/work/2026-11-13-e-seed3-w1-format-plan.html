The problem

The work

In short: pick formatter settings that keep the code's long-line style, so the one-time change is as small as it can be. Format once, with no other change. Then add the format check to lint.

  1. rustfmt.toml: max_width = 160, use_small_heuristics = "Max". Nothing else.
  2. One commit: cargo fmt, no other edit.
  3. .keel/config.toml: [check] lint = "cargo fmt --check && cargo clippy --all-targets -- -D warnings". Rule-bearing: your keel mr commit.
