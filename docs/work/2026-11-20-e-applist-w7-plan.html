The app's locked-down core, its two-way link to the window, one project, a signed build and one test alert. It replaces the first frame's plan.

The problem

The alert and the list need an app. It reads worker-written text, so it must be closed to it from day one. The first try built one too fast; its code is dropped. Nobody knows yet whether a free signature lets macOS show alerts.

What you get

  • Keel.app on your Mac, built from this repository.
  • A bare page: where keel, git and claude are, and a "Send a test alert" button.
  • The test alert, which settles whether you need Apple's paid membership.

How it works

  1. The window asks the app's core for six named things, such as "add a project". Anything else is refused.
  2. The core tells the window when something changed, by named signals only the app's window hears.
  3. The window never sends a path or a command. A folder or a program is chosen in a macOS dialog the core opens.
  4. The core runs git with fixed lines, no shell and git's risky settings off.
  5. It reads your PATH once from your login shell.
  6. Settings and the project list live in the app's own folder. Nothing is written inside a project.
  7. Closing the window leaves the app running, so alerts still come.

What needs you

  1. One typed rules commit, once the core's first tests exist, so the usual checks run them. The worker sends you the exact line.
  2. At your Mac, at the end: build, install and open the app; send the test alert.
  3. Only if no alert shows with either free signature: decide Apple's membership.

What it makes

  • The app's core, its link to the window, a bare page, the build.
  • Tests of the core that run on Node alone, so the usual checks install nothing.

How you'll know it worked

  • The app opens, finds keel, git and claude, and says its PATH came from your login shell.
  • The test alert shows, or the result names the signature that failed and asks you.
  • With the window closed, the app stays in the Dock.
  • The usual checks run the core's tests, with nothing installed.
  • Tests prove refusals: an unknown request, a stranger's request, free text, an unlisted signal, an inherited git setting.
