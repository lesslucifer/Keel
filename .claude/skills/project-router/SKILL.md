## Sign-off sequences
Default per the keel-workflow skill; exact owner commands in the keel-router
skill's `references/commands.md` (with `ID=vuluu`). Keel's differences:
- **WU**: default (worker gates → router verifies → owner `keel mr confirm wu <tip> --as vuluu --target epic/<E>` → owner `git merge --no-ff` into the epic → next worker). Always pass `--target epic/<E>` with a sha (commands.md). E-ROUTER exception: its WUs are ungated (no notes, no sign-off); plain commits on `wu/E-ROUTER/<slug>`, merged `--no-ff` into the epic.
- **WU, the GitHub path** (keel-router `references/worker-ops.md` "The GitHub flow"; until E-GHFLOW2's landing 1 the sign-off stays typed and the merge local): the test note on the tip → `push`, `pr-open`, `issue` → the review's `cr` note → `push`, `pr-open` → gate red only on 8, `CHECKS state=success` → `pr-ready` → the R50 stopgap (keel-router "Keel pre-sign check": the watchdog's latest report names no admin-dir problem) → owner `keel mr confirm` (typed) → `push` (the `mr` note) → owner `git merge --no-ff` locally → router `push epic/<E>` → `MERGED` → `issue` for the WU and the epic. After landing 1, the owner's approval on the head is the sign-off (E-GHFLOW2.W3); after landing 2, GitHub merges (W4).
- **WU with a rule-bearing file** (`rule_bearing` in `.keel/config.toml`: `AGENTS.md`, `docs/*.html`, `skills/`, `templates/`, `.keel/`, `.claude/skills/`, `.claude/settings.json`, `scripts/router-guard.jq`, `scripts/router-inbox.sh`, `scripts/router-worker.sh`, `scripts/router-file-guard.sh`, `scripts/router-watch.sh`, `scripts/router-gh.sh`, `scripts/router-gh-watch.sh`, `scripts/router-gh-command.jq`, `.claude/agents/`; `.keel/mr-allowed` always): default — only that file staged → owner `keel mr commit … --as vuluu` → fresh worker re-gates the new tip → owner confirms and merges.
- **Epic close**: merge `main` into the epic first (resolve `.claude/settings.json` / `.gitignore` per DEC-12: keep the settings holding the router config, re-run `keel init` on top); distil every T3 doc and archive it out of git (keel-distill skill) so nothing T3 reaches `main`; then owner `keel mr confirm epic <tip> --as vuluu --report docs/.archive/<date>-<slug>-epic-result.html` → `git merge --no-ff epic/<E>` in the main checkout → push. Worked example: E-SEED, signed on `9a8f255`, merged as `e5a04cf`.
