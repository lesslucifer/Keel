The main case, in a test

  1. The browser view opens with no project.
  2. The screen shows "No project yet" and one black pill, Add a project.
  3. Click it. The sample core adds a project and says the state changed.
  4. The screen asks again and shows the project with an outline Remove pill.

Your five-minute look

  1. In the app folder: npm ci.
  2. npm run dev:browser, then open http://localhost:5173/browser.html. Switch sample states by the links in the line at the top.
  3. Switch System Settings, Appearance, between Light and Dark: the page follows. Or click Light or Dark in the top line.
  4. Stop the server (Ctrl-C). npm start: the app from source, with your real tools. Choose opens the macOS dialog. Send a test alert shows the alert.
