The job

The doc check refuses a finished doc with an unquoted diagram label, and a finished epic plan with no "what changes for you" section or with more than 300 words above its first WU. Each error names the fault.

Example

  1. An agent writes an epic plan and marks it ready.
  2. Its diagram has A[Build step].
  3. The check says: unquoted diagram label [Build step]; write ["Build step"].
  4. The agent adds the quotes. The check passes.

1Where does the counted top start?At the main content, not the title block. The epic plan's "about 290" was counted this way: 294.
2What is a word?Anything between spaces with a letter or digit in it. A "·" or an arrow is not a word. Diagram text counts: you read it.
