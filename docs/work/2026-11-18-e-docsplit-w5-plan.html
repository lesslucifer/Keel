E-DOCSPLIT.W5 · Slim the knowledge bases

Decisions keep current truth only. Use cases and the backlog become data files, with no page.

WU plan · v1 · 2026-11-18 · T3 · Keel · W5 of the epic plan · rules from the W1 inventory (DEC-69) · its data file sits beside this page

The problem

Decisions, use cases and the backlog hold about 56,600 words, much of it history: how a choice was reached, rows already done. Agents read it all to find today's truth. W1 set the cure: keep current truth, and turn what only agents read into data.

After W5, each decision page is under 5,000 words, red above that; use cases, the backlog and the three indexes are data files with no page; and every id that existed before, or is cited anywhere, is still found.

How you approve

  1. You comment here; the worker answers. You tell the router "W5 approved"; the build starts.
  2. Four rule files wait in the worktree. The router gives you one keel mr commit; you run it.
  3. The result shows each file's words before and after.
  4. W5 reaches the epic as a pull request. Your approval signs it; auto-merge merges it.

How you'll know it worked

  • Each decision page is under 5,000 words; one over it is red.
  • No use-case or backlog page is left; each has its data file.
  • The id check finds every id from before, and every cited id, after.
  • keel verify-doc over all docs is green.

Tests: none. W5 changes no code, so the gate exempts it; the checks above stand in.
