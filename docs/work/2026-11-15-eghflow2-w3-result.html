Deviations

  • The writer's token reads pull requests (plan open point 2): pull-requests: read beside contents and statuses write. Reading the reviews needs it; it writes nothing there.
  • No CI re-read in check 8 (open point 3): the writer re-reads the review before it writes; check 8 checks the note's bindings offline. Backlog github-flow G7.
  • The github tier is opt-in: a config that names no [mr] tiers still accepts the three typed tiers only. The plan did not say; a default that let an approval sign would widen every project that never asked.
  • An approval never signs a roster change or a waived review, and never bootstraps a roster: those stay the typed sign-off (W7 brings them to comments).
  • One fix beyond the plan: R50's check reads a gitdir that git wrote relative (worktree.useRelativePaths) from the admin dir.
  • G5's W2 corpus cost: the curl stub is written once per run now, but the 507 guard probes still run serially (left in G5).
  • Two probe commands were denied by the session's permission check (a scratch git notes merge experiment); not routed around. The hermetic router-gh tests settled the question instead.
