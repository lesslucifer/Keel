How to use this log

Append-only. Add a new row at the bottom for each ruling: date, WU or topic, the decision, and where it is recorded (doc row, htmldoc comment id). Never edit or delete a past row; if a ruling is reversed, add a new row that names the one it replaces. The epic-level questions decided before this log existed (Q1 onward) stay in the seed plan's decisions table and are not copied here.
