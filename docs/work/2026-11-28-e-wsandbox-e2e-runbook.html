Your run of the epic's end-to-end check in the probe clone: what a worker may do, stop and resume, the efforts, and the router's and watchdog's new abilities.

Why you run it

The router runs main's launcher, which has none of this epic's changes. So the check runs the epic's own launcher in the probe clone, /Users/nguyenvanluong/Documents/proj/misc/Keel-probe, with Haiku workers. Only you can do that: it needs claude and the launcher, which no worker may run.

Use one terminal from start to end: step A1 sets the names every later step uses. Every command writes to one log, $HOME/keel-wsandbox-e2e.log. When you finish, or when a step fails, send that log to the router. A failure does not stop the run unless the step says so: note it and go on.
