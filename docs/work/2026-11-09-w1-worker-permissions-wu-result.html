Outcome

Delivered. scripts/router-worker.sh now passes the grant table to every claude -p it starts. The allow list (--allowedTools) holds Bash(c) and Bash(c *) for cargo build|test|check|clippy|fmt and keel preflight|verify-doc|verify-dod|notes write|lint|check. The deny list (--disallowedTools) holds keel mr and cargo run, bare and " *". spawn and resume take an optional trailing --permission-mode acceptEdits|plan. It defaults to acceptEdits on every run and is never inherited by a resume. It is written to the run dir's permission-mode file and printed on the RUNNING line. bypassPermissions, dontAsk, default and an empty value are refused with "permission mode must be". A missing value, an unknown option or an extra argument is refused with the usage line. In every refusal nothing starts. .claude/settings.json and scripts/router-guard.jq are unchanged, as the plan's F4/F5 and non-goals require. Every bullet of the plan's Expected holds on the tip, except the live bullet, which is evidence only and could not be run from this session (see Deviations).
