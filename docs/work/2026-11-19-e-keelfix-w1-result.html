What happened

Delivered. The pre-commit hook, the commit-msg hook and keel mr commit read the rules file committed at the branch's tip. When nothing is committed yet, they read the staged file and say so in one line. With neither, the commit is refused and told to stage the file. Every other command still reads the folder's file, as planned. After review round 1, a commit that stages a rules file keel cannot read is refused before it lands.
