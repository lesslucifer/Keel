The problem

Workers stop on their own limits and the step comes to you: no local port (14 tests switched off), no package install, the automatic reviewer refusing harmless scratch work, and a pinned list of sites for you to keep. On 26 November you ruled every point. This WU builds parts 2–4 as one change.

How it works

  • The launcher's sandbox gains allowLocalBinding.
  • The five hosts stay as the base because what an empty list does is still unproven, so registry.npmjs.org joins them; no lock is added, so the reviewer widens each call. A site it allows can receive what the worker read.
  • The launcher gives the worker a private pnpm home in the temp folder, so no package unpacks into the worktree's blocked .vscode path and your own store is never touched.
  • A new helper, scripts/router-scratch.sh, makes the throwaway repo; it refuses any path that is not a fresh temp dir it made itself. Mode stays auto; WebFetch stays with the reviewer and is recorded.

How you approve

One branch carries parts 2–4. I commit the tests and docs; the rule-bearing files — the launcher, the helper, the config, the persona, the skills, the install page — are staged together for your one keel mr commit. Then one review, one signature, one --no-ff merge.

What it makes

A worker session that serves a port, adds a package, or sets up a scratch repo on its own, with no step for you — within the bounds written above.
