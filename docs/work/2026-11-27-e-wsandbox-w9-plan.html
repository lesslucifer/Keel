A worker starts at the level your ruling names, on either host, and a planner gets more than a builder.

The problem

Workers start at one effort level read from one file, but the two hosts that start them name effort differently. The file still says medium by default and high for design, review and debugging, so a review runs at planner effort; on the newer host an omitted effort silently runs at high. On 26 November you ruled: later workers low, planner workers high. This unit writes that one policy and the mapping each host needs.

How it works

  • The config carries one level per role: low by default, high for a planner, and the allowed levels are low and high. A policy missing the planner level is refused whole.
  • On the older host the launcher takes a role, worker or planner, and passes the matching level to the tool. Any level outside the policy is refused before a session starts.
  • On the newer host the router passes the level as the worker's effort every time, because leaving it out means the host's high.
  • One skill holds the numbers; the generic router skill holds the host mechanics and points at it. No skill still calls medium the default.
