The main case, in a test

  1. The browser view opens with no project.
  2. The screen shows "No project yet" and Add a project.
  3. Click Add. The sample core adds a project and says the state changed.
  4. The screen asks again and shows the project with Remove.

Your five-minute look

  1. In the app folder: npm ci.
  2. npm run dev:browser, then open http://localhost:5173/browser.html. Switch sample states by the links in the amber line at the top: no project, a missing tool, the PATH fallback, a refusing core, a failing core, a slow one.
  3. Switch System Settings, Appearance, between Light and Dark. The page follows.
  4. Stop the server (Ctrl-C). npm start: the app from source, with your real tools. Choose opens the macOS dialog. Send a test alert shows the alert.
