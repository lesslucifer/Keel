T3 · wu-result · tracked at the W15 tip, archived at the epic re-gate (distilled to backlog B14) · 2026-11-10 · branch wu/E-SEED2/w15-hook-reflog-env · owner ruling 2026-11-10: every code review waived, no plan doc

Delivered. The second merge of epic/E-SEED2 into main 0dad93f was refused because six tests/mr.rs fixtures failed under the hook's keel check with git rev-parse epic/E-SEED2^{commit}. Git exports GIT_REFLOG_ACTION="merge epic/E-SEED2" to its hooks. A fixture's own git merge keeps a value it inherits, and the fixture's pre-merge-commit keel then reads it (src/gate.rs verify-dod hook) as the merge source. Keel's child spawns (no_git_env(.., false), which covers check commands) and the tests' common::cmd now also strip GIT_HOOK_ENV: the reflog action, the editor, and the author and committer name, email and date. A probe hook observed git exporting all of these to its hooks.

The owner waived the plan doc and every code review, so the cr/v1 PASS records that waiver. GIT_EXEC_PATH is also exported to hooks but is not stripped: it only points at the running git's own helpers. Keel's own git calls keep the hook env.

Commit 8cc6c4e, which changes src/main.rs, tests/cli.rs, tests/common/mod.rs and docs/backlog/e-seed-v2.html.
