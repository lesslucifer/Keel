What happened

One policy now lives in the config: a worker low, a planner high, and only those two levels. The launcher takes a role, worker or planner, and passes the matching level; it refuses anything else by name, including medium. Both router skills say the same thing — one names the keys, the other how each host is told — and the newer host is always given the level, because leaving it out would mean high. Six rule-bearing files went to you as one commit; the rest are docs and tests. No code changed after either review.
