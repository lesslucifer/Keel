E-DOCSPLIT · A short doc for you, a data file for agents

Split each plan and result in two, and slim today's docs.

T3 · epic plan · draft v1 · 2026-11-17 · Keel

The problem

Each plan and result is one HTML file with three readers: you, an agent, and Keel's checks. It serves none of them well. You get long pages full of tags. Agents spend tokens writing HTML. The checks dig facts out of it. This epic gives each its own doc: a short page for you, and a data file for agents and checks. It also slims today's docs to current truth.

What changes for you

WhenTodayAfter
You read a plan or resultOne long page, written for three readersA short page, written only for you
A check finds a gapIt names a missing tag in the pageIt names a missing field in the data file
You open the decisions, use cases, backlog or architectureLong, with history and replaced rowsShort: current truth only
You approveThe epic plan, then each WU planThe same, and first a table of where each doc lives

Example: a WU plan after this epic

  1. An agent writes the plan's data file: the requirement, the tests, its epic.
  2. The check reads it and names a missing test plan. The agent adds it.
  3. The agent writes a one-screen page for you, in plain words.
  4. You comment on the page. The agent fixes both.

Terms

Data fileA YAML file for agents and checks. You never need to read it.
NoteData git keeps beside a commit, outside the files.
DistillMove a finished doc's lasting truth into a permanent doc, then archive it.

W2 · The check reads the data file

In short: keel verify-doc checks a plan's or result's data file against its role's fields. The page is checked only for what a reader needs: links, diagram labels, length.

  • src/verify_doc.rs: a data-file module. Per role: required fields present and non-empty, unknown keys named (the typo guard), status: draft silent, WU ids and their dependencies resolve, a collapsed epic is the union of both roles.
  • The page side keeps the link and label checks and gains W1's word caps. The data-item / data-wu scan goes.
  • src/main.rs: verify-doc with no path, and the write hook (DOC_POST, today *.html only), take data files too. The DSH dsh-doc-gate plugin's file filter is checked the same way.
  • yaml-rust2 (already a pinned test dependency) becomes a runtime one.

Details

Acceptance

  • A ready plan or result with a missing or empty field in its data file is red at the write, and the message names the field.
  • A page carries no checklist tags; it is checked only for links, diagram labels and W1's cap.
  • keel mr confirm finds the result report through its data file and attests the page's bytes.
  • A page and its data file archive together under one lineage, and the epic gate is green.
  • The four doc skills and AGENTS.md describe the split; keel init ships it.
  • Decisions, use cases, backlog, architecture and install are each under W1's cap, with every cited id still found.

Use cases

UC-DOC-1 rewritten: the checklist is read from the data file. UC-DOC-3 amended: a pair archives as one doc. UC-DOC-5 amended: the pull request names a doc by its data file. UC-MR-1 and UC-MR-2 amended: the report is found by its data file's role. A new UC-DOC-6: every page kind has a word cap. UC-DOC-2 and UC-DOC-4 unchanged.

Not in this epic

  • Generating one doc from the other: both are written by hand, each for its reader.
  • The gate's notes (test, cr, mr, dod) keep their schemas; the doc note changes only for pairs.
  • htmldoc itself, and skill files (they stay markdown).
  • E-GHSETUP's work: GitHub setup for any project, and install's GitHub section.
  • Checking follow-up destinations (open point 8).

End-to-end test

One flow through the built binary in a temp repo (tests/suite/docsplit_e2e.rs): an epic with one WU writes its plan pair, and a data file missing a field is red at keel verify-doc; fixed, it is green. The WU commits its result pair, writes its notes, and the test signer's keel mr confirm wu finds the report through its data file; the WU merges. At close the pairs are archived with one --distill each, and keel verify-dod epic is green. No waiver.
