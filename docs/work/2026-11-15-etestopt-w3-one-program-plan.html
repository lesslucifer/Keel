The ten test files become modules of one program, so cargo test runs every test in one pool and never stops at the first failing file.

The problem

Each file under tests/ builds into its own test program, and cargo test runs the ten programs one after another. The router file alone holds the run for 10 to 24 s while the cores sit idle. And when one program fails, cargo test stops there: the files after it never run, which hid five router reds in E-SEED2.W15.

The work

Every integration test lives in one test program, tests/suite/, with the same names and assertions, and a test fails whenever a file would build as another test program or a file in the suite is not part of it.

Epic E-TESTOPT, its W3 block and open points 2 and 3 · Trawler E-GATEPAR2.W4 (97e34a31) · the E-SEED2.W15 lesson (cargo stops at the first failing program).

cargo test runs two test programs, the unit tests and suite, and passes 334 plus this WU's new tests, with 0 failures, in a worker's sandbox on the stock PATH. A planted tests/stray.rs turns the guard red with the move recipe in its message.

  • git mv tests/<f>.rs tests/suite/<f>.rs for all ten files. tests/suite/main.rs declares #[path = "../common/mod.rs"] mod common; and one mod per file. Each mod common; becomes use crate::common;. tests/common stays where it is, so W1's PATH guard keeps its one exclusion.
  • A new module tests/suite/layout.rs: the guard, and a pure check it calls, unit-tested on made-up listings.
  • The thread cap (.cargo/config.toml, [env] RUST_TEST_THREADS = "8") only if the after-run at 8 threads beats the default by 10 % or more, twice.
  • .keel/config.toml is untouched: [check] test stays cargo test.

Test plan

  • Integration (tests/suite/layout.rs): the guard reads the real tests/ tree and Cargo.toml. Red first: with a planted tests/stray.rs it fails and names the file and the move; the plant removed, green. The same for a tests/suite/ file left out of main.rs.
  • Unit: the pure check, on made-up listings: a clean tree, a stray top-level file, a second <dir>/main.rs, an undeclared module, a [[test]] table, a non-.rs file (ignored).
  • The move itself: the passed count before (334) equals the count after minus the new tests; the list of test names before and after, compared by name with the module prefix dropped, is identical.
  • Observable: cargo test --no-fail-fast before and after, stock PATH, twice each at the default threads and twice at 8, load recorded.
